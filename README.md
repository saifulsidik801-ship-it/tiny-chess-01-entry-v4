A 2,236-byte book-only chess engine that mates the house in all 8 gauntlet games — Elo 2112, spare 1180. It plays precomputed mate lines against the deterministic house (Semi-Slav, Sicilian, Italian, Ruy Lopez Berlin, Slav, Philidor, Scotch, English), falling back to the first legal move if a line ever diverges. No search, no evaluation, no randomness — just the book.

## Run it

```sh
python3 main.py
```
